# Maya Fey / 绫里真宵 — Codex 桌宠

一只绫里真宵主题的 Codex 桌宠。**Let Maya Fey, spirit medium extraordinaire, lend you a hand!**

![绫里真宵待机动画预览](assets/idle-preview.gif)

## 安装

1. 在 GitHub 仓库页面选择 **Code → Download ZIP**，下载并解压（也可以克隆仓库）。
2. 将 `maya-fey--kbz1121` 文件夹复制到 Codex 桌宠目录：
   - macOS / Linux：`~/.codex/pets/`
   - Windows：`%USERPROFILE%\.codex\pets\`
3. 重启 Codex，在桌宠选择界面选择 **Maya Fey / 绫里真宵**。

安装后，`pet.json` 和 `spritesheet.webp` 应直接位于桌宠文件夹内，例如：

```text
~/.codex/pets/maya-fey--kbz1121/
├── pet.json
└── spritesheet.webp
```

## 素材包信息

- Codex Pet v2 图集格式
- 图集为 8 × 11 帧，尺寸 1536 × 2288 像素
- 包含标准动画状态和 16 个视线方向
- `submission.json` 保存目录投稿和署名信息；本地安装不需要它。
